# DengueAI 🦟 - DSS Prediction System

DengueAI adalah sebuah sistem cerdas (Sistem Pendukung Keputusan Medis) berbasis *Machine Learning* yang dirancang untuk membantu tenaga medis mendeteksi risiko Dengue Shock Syndrome (DSS) secara dini dengan cepat dan akurat.

## 🌟 Fitur Utama
* **Deteksi Instan**: Memprediksi tingkat risiko DSS ("High Risk" atau "No Risk") hanya dalam hitungan detik.
* **19 Parameter Klinis**: Menggunakan 19 indikator klinis dan hasil laboratorium standar (seperti Demam, Mual, Trombosit, Hematokrit, dsb) untuk akurasi yang lebih presisi.
* **Antarmuka Medis (Clean UI)**: Dibangun dengan UI/UX modern dan interaktif yang memudahkan tenaga kesehatan menginput data tanpa kebingungan.
* **Compact Result**: Menampilkan peringatan warna interaktif sesuai tingkat bahaya pasien.

## 🛠️ Teknologi yang Digunakan
* **Backend**: Python 3, Flask, Gunicorn
* **Machine Learning**: Scikit-Learn (Algoritma Random Forest)
* **Frontend**: HTML5, Vanilla CSS (Medical UI/UX Theme), FontAwesome

## 👨‍💻 Pengembang
Dikembangkan oleh **Wahyu Kusuma Wardhana** untuk keperluan analisis dan screening kesehatan pendahuluan. Aplikasi ini tidak dirancang untuk menggantikan diagnosa klinis dari dokter sepenuhnya.
